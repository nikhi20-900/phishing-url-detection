## 1. Executive Summary & Verification Mandate

During Phase 4 external validation, evaluating the frozen Random Forest classifier against an external test corpus of 500 curated legitimate URLs yielded an alarming initial metric:
- **True Negatives:** 30 / 500 (6.00% Recall on benign URLs)
- **False Positives:** 470 / 500 (**94.00% False-Positive Rate**)

In accordance with Issue #4 review priorities, this validation report executes the 6 priority tasks to confirm whether the 94% FPR is supported by reproducible implementation, isolate the exact classification bias, and determine whether stripping trailing slashes solves the problem or merely treats a minor symptom.

### Key Audit Findings
1. **The 94% FPR is Empirically Confirmed:** Recalculating predictions across all 500 curated legitimate URLs confirms exactly 30 true negatives and 470 false alarms.
2. **Trailing-Slash Stripping is Insufficient (86.8% FPR Remains):** Stripping the trailing slash from root domains recovers only 36 additional true negatives (increasing TNs from 30 to 66). The remaining **434 URLs (86.80%) remain false positives** because they contain genuine directory subpaths (`/research`, `/academics`) and query parameters (`?q=...`).
3. **The Root Cause is an Extreme Covariate Shift in PhiUSIIL:** 100.000% of the 134,850 legitimate URLs in the PhiUSIIL training dataset were syntactically restricted to `https://www.<domain>` with zero paths, zero trailing slashes, zero query parameters, and hardcoded `www.`. The model learned that any path or query delimiter implies phishing.
4. **Production Assets Remain Frozen:** No code in `src/`, model weights, or Phase 3 benchmark artifacts were altered.

**Provenance Clarification:** The 134,850 figure represents the entire legitimate population of the PhiUSIIL benchmark. The actual model training partition contained **107,880 legitimate URLs**, across which the exact same 100.000% syntactic template invariant holds.

## 5. Priority Task 4: Recalculate 500-URL Confusion Matrix & Normalization Audit

We evaluated the exact same 500 independently curated legitimate URLs (`data/external/legitimate_curated.csv`) across three distinct normalization conditions to isolate the precise impact of trailing slashes:

### 5.1 Evaluated Conditions ($N=500$ Identical Records)

1. **Condition 1 (Raw Ingested URLs):** Evaluated strictly as curated.
   - Result: **TN = 30, FP = 470 $\rightarrow$ FPR = 94.00%**.
2. **Condition 2 (Root Trailing-Slash Stripping):** Stripping `/` only if `parse_url(u).path == '/'`:
   - Transformation: `https://www.stanford.edu/` $\rightarrow$ `https://www.stanford.edu` (subpaths like `/research/` left untouched).
   - Result: **TN = 66, FP = 434 $\rightarrow$ FPR = 86.80%**.
3. **Condition 3 (All Trailing-Slash Stripping):** Stripping `/` from any URL where `u.endswith('/')`:
   - Transformation: Root URLs and subpaths ending in `/` stripped.
   - Result: **TN = 66, FP = 434 $\rightarrow$ FPR = 86.80%** (Identical to Condition 2).

### 5.2 Controlled Feature Deltas Caused by Trailing-Slash Stripping
Stripping the trailing slash from `https://www.stanford.edu/` changes exactly 4 features out of 18, leaving the remaining 14 features strictly invariant:
- `URLLength`: 25 $\rightarrow$ 24 ($-1$ character)
- `LetterRatioInURL`: 0.440 $\rightarrow$ 0.458 ($11/25 \rightarrow 11/24$, $+0.018$)
- `NoOfOtherSpecialCharsInURL`: 2 $\rightarrow$ 1 ($-1$ special character, removing the slash)
- `SpacialCharRatioInURL`: 0.080 $\rightarrow$ 0.042 ($2/25 \rightarrow 1/24$, $-0.038$)
- All other features (`DomainLength`, `TLDLength`, `NoOfSubDomain`, `IsHTTPS`, `Digits`, `Query`) remain completely unchanged.

### 5.3 Forensic Breakdown of the Remaining 434 False Positives
- **416 URLs (95.85% of remaining FPs):** Contain legitimate directory subpaths (`/research`, `/academics`, `/documentation`).
- **99 URLs (22.81% of remaining FPs):** Contain dynamic query strings (`?ref=docs`, `?lang=en`).
- **18 URLs (4.15% of remaining FPs):** Are bare root domains without `www.` (e.g., `https://stanford.edu` vs `https://www.stanford.edu`).

**Critical Insight:** Stripping trailing slashes resolves only **7.20%** of the false alarms (36 root domains). The remaining **86.80%** of false alarms are driven by authentic path and query structures.
